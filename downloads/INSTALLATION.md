# Installer Marée sur Android

Fichier : `Maree-Android.apk` (22 775 269 octets).
Version de test : 0.1.0, Android 10 ou plus récent.

1. Télécharge le fichier APK depuis ce dépôt GitHub.
2. Sur ton téléphone, ouvre Mes fichiers → Téléchargements → Maree-Android.apk.
3. Choisis Installer. Si Android le demande, autorise cette source dans les paramètres, puis reprends l’installation.
4. Ouvre Marée.

SHA-256 : `ec64462e62d02caa6547d1bb634a7cef38c55e504abdeba4b47c5fe78453a494`.

La compilation, huit tests unitaires et Android Lint ont réussi. La signature et l’installation sur Android 14 ont été vérifiées. Le suivi complet reste à vérifier sur téléphone ; le coach IA, les abonnements et la synchronisation ne sont pas encore implémentés.
