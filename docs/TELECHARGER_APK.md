# Télécharger l’APK sur Android

Fichier actuel : **Selkie-Android-0.12.1.apk**, environ 26 Mo, dans la branche `maree-apk-download`.

Les liens directs ont affiché une erreur 404 sur le téléphone de l’éditeur. Un téléchargement réussi depuis le cloud, qui dispose d’un accès GitHub au dépôt, ne prouve pas que le lien est accessible publiquement dans un autre navigateur. Il ne faut pas annoncer les liens raw comme des téléchargements publics garantis.

## Essayer l’accès avec le compte du dépôt

1. Ouvrir Chrome et se connecter à [GitHub](https://github.com/login) avec le compte propriétaire `abdulmalikkakar48-blip` ou un compte ayant accès au dépôt.
2. Ouvrir [la page de l’APK](https://github.com/abdulmalikkakar48-blip/Code-1.1/blob/maree-apk-download/downloads/Selkie-Android-0.12.1.apk).
3. Si la page est accessible, choisir **Download raw file** (icône de téléchargement) ou **View raw**, puis retrouver le fichier dans Téléchargements.

Si la page affiche encore 404 après connexion au bon compte, l’accès ou l’adresse effective du dépôt doit être vérifié avant de proposer un autre lien. Ne pas recommander de désinstaller l’application pour résoudre une erreur de téléchargement.

Les [sources 0.12.1](../downloads/Selkie-Android-0.12.1-source.zip) et [contrôles 0.12.1](../downloads/VALIDATION-0.12.1.md) correspondent au nouveau fichier. ## Distribution sans connexion

Une distribution publique doit être testée depuis un accès distinct de celui du cloud et, pour ce cas, confirmée sur le téléphone. Un dépôt public séparé contenant uniquement l’APK ou un hébergement de fichiers adapté peut être préparé. Rendre tout le dépôt de développement public exposerait aussi ses sources et son historique ; ce n’est pas nécessaire pour distribuer l’APK. Une release d’un dépôt privé reste soumise à son contrôle d’accès.

L’API GitHub est actuellement bloquée par la politique réseau de cet environnement. La création d’un hébergement public séparé n’a donc pas été effectuée. Aucun secret ne doit être inclus dans un lien de téléchargement ni communiqué dans le chat.
